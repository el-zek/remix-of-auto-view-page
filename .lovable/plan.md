# Simplify the authentication entry screen

## Changes
- Remove the first-launch “Slide to continue” screen entirely so `/auth` opens directly to the authentication choices.
- Remove the logo, welcome heading, supporting text, icons, and footer wording from the authentication choice screen.
- Keep only two understated actions: **Sign in** and **Sign up**.
- Restyle both actions as slim, premium controls while preserving the existing sign-in and sign-up forms and behavior.

## Verification
- Confirm the simplified screen appears immediately on first and returning visits.
- Confirm both actions still open the correct forms on desktop and mobile-sized screens.
